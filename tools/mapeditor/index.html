? Tools & shortcuts

Tools
B🖌️ Paint — pick a tile, click/drag to paint. Shift-drag = fill a rectangle.
F🪣 Fill — flood-fill the contiguous same-tile region.
E🧽 Erase — paint grass back (Shift-drag = rectangle).
P🌳 Place — click to drop the selected prop / building / NPC; drag to lay a line of props (tree lines, forests).
V➤ Select — click an object, or drag a box over several; then drag or arrow-key them to move, Ctrl+D duplicate, Del remove.
D🚪 Door — drag a map-level warp zone. For a building, select the facade and add an embedded entrance so collision opens with it.
S👾 Spawn — drag an enemy-encounter zone.
T⚡ Trigger — drag an event zone (id + once).
—📖 Sign · ☎️ Phone · 🏧 ATM — click a point. 🥾 Patrol — click waypoints (Esc finishes). 🪞 Reflect — drag over water.
H✋ Pan — drag to move the view (or middle-mouse-drag anytime).
Keyboard
Ctrl+ZUndo (a whole stroke/drag is one step).
Ctrl+Y / Ctrl+Shift+ZRedo.
Ctrl+DDuplicate the selected object (offset 1 tile).
RRotate the selected prop 90° (face any of 4 directions). Buildings resize instead of rotate.
drag ▪Drag a selected object's edge / corner handles to resize it — works on buildings, props (unrotated) and NPCs. In-game size & collision scale with it; set exact ×'s in the inspector.
←↑↓→Nudge the selection 1 tile (Shift = ½ tile).
[ / ]Smaller / larger paint brush.
Del / BackspaceDelete the selected object.
WheelZoom (or use − / + / ⤢ Fit in the toolbar).
overlaysToggle editor-only zones, points, labels, routes, and selection handles for a clean art preview.
Workflow
Paint the ground → place props/buildings/NPCs → add doors & spawns → set ⚙ Settings (music, area…) → run ✓ Check → ⬇ Export the TypeScript and paste it into src/data/maps.ts. Work auto-saves in the browser.
