# Reference art — drop folder

Put **your own** style-reference images here (concept art, ChatGPT-authored mockups,
photos of layouts you like) to reference while building maps. This is where reference
material lives alongside the masters.

## What goes here
- Your **original** concept art + ChatGPT-authored EarthBound-style mockups (same
  pipeline as `assets/art/masters/world/otterbrook-CONCEPT-locked.png`).
- Screenshots of **our own** game for before/after comparisons.
- Layout sketches / blueprints.

## What does NOT go here
- **Copyrighted third-party game art** (e.g. Nintendo/EarthBound screenshots or ripped
  sprite sheets). We build **original EarthBound-*style*** art via the ChatGPT → PNG
  pipeline (see `CLAUDE.md` + `docs/ART_PIPELINE.md`); the fidelity target is Onett-*grade
  design language*, **not** a pixel-copy. Keep third-party reference in an external
  moodboard, not in the repo/build.

## How to add a file
Chat-pasted images can't be written to disk by the agent — they're inlined in the
message. To save an image here, drop the file in via your file explorer (or
right-click → *Save image as…*) into `assets/art/masters/reference/`, then tell me
the filename and I'll wire it into the design docs / catalog it.

The **design lessons** distilled from EarthBound's map archetypes (for building our
remaining maps + transitional areas) live in
[`docs/EARTHBOUND_MAP_REFERENCE.md`](../../../../docs/EARTHBOUND_MAP_REFERENCE.md).
