# Reference image catalog — EarthBound archetypes by level

Third-party **EarthBound** (Mother 2) reference screenshots + fan maps, saved as mood/style
reference for the [EarthBound-stylization overhaul](../../../../docs/EARTHBOUND_MAP_REFERENCE.md).
Filenames follow the **EB-area → our level** convention (user directive 2026-07-04):
Onett=1, Twoson=2, Threed=3, Fourside=4, then Winters=5, Summers=6, Scaraba=7, Dalaam=8,
Deep-Darkness=9. Non-level buckets: `haven_` (recurring safe-haven — Saturn Valley),
`transition_` (between-town wilderness/cave routes), `misc_` (unresolved).

> ⚠ **Levels 5–9 are a judgment call.** The user's numeric convention names the numbered EB
> towns cleanly (2/3/4); Winters/Summers/Scaraba/Dalaam/Deep-Darkness were assigned 5–9 in
> EarthBound progression order. Adjust the `lvlN_` prefix if the intended chapter differs —
> the area name in each filename keeps it unambiguous. NB this differs from the nuanced
> mapping in `docs/EARTHBOUND_STYLIZATION_OVERHAUL.md` (Twoson=Brickton, Fourside=Chandrapore, …).
>
> **IP:** these are copyrighted Nintendo screenshots kept only as external *style* reference;
> we author original EB-*style* art via the ChatGPT → PNG pipeline. Do not ship/trace them.
