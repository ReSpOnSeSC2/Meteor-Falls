# ☄️ Chapter 1 — AI Image-Gen Prompts (Expanded Opener)

**Purpose.** Generate every NEW asset the expanded Chapter 1 needs, in our
established house style, via the ChatGPT / imagegen → PNG workflow. You generate
the masters PNG; then slice/downscale into the runtime sheet and wire it in
`src/spritegen/authored.ts` per [`ART_PIPELINE.md`](ART_PIPELINE.md).

> **Status (2026-06-16).** The two new climb maps (HICKORY TRAIL, WHISPERWOOD
> RISE) are LIVE and gray-boxed on shipped sprites — the prompts in **§1** make
> them bespoke. **§2–§5** are the assets for the next build phase (Downtown
> Otterbrook, its interiors, the new cast, the first car). Nothing here is
> generated by the agent — these are prompts for you to run.

---

## How to use this file

1. Copy the **STYLE PREAMBLE** (below) verbatim, then paste ONE asset prompt
   after it. Generate. Keep the raw drop in `assets/art/masters/generated/`,
   then promote the background-removed `-transparent` master into the right
   `assets/art/masters/<category>/` folder.
2. Slice/downscale to the **runtime frame size** noted per asset (native ×4 per
   ADR-110 — tile 16→**64**, character 24×32→**96×128**, bust 32×32→**128×128**,
   battler 28×36→**112×144**). Export the runtime sheet into the listed
   `assets/art/…` path.
3. Add the `key` + URL to the matching list in `authored.ts`
   (`WORLD_PROP_ART`, `NPC_CHARACTER_ART`, `ENEMY_BATTLE_ART`, …) so it overrides
   the boot texture.

### ⬛ STYLE PREAMBLE (paste before every prompt)

```
House style: "warm 16-bit / GBA JRPG Americana." EarthBound is the layout and
tone reference; Mother 3 is the color and animation-polish reference — study the
principles, copy nothing. Authored pixel art with strong taste: readable
silhouette at small size, charming proportions, hand-placed pixel clusters, a
restrained palette with clean ramps. Bright but NOT neon. Cleanly outlined but
not always hard black outline. Simple at first glance, rich on the second look.
Funny, warm, and slightly strange. Handcrafted, not filtered. AVOID: pillow
shading, noisy multi-shade gradients on tiny sprites, over-smooth RGBA, HD
bloat, procedural ellipses as anatomy. Output on a FULLY TRANSPARENT background
(no checkerboard baked in), top-down/three-quarter overworld perspective to
match an EarthBound-style tile world. Crisp pixels, no anti-alias halo.
```
