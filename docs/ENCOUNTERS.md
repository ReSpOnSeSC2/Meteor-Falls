# METEOR FALLS — Encounter Pressure Report

_Generated by `npm run encounters` (S15g Movement Two, ADR-045). One row per canon map._

**How to read it.** `density` is enemies per 1600×900 screen-equivalent — the §A9 band metric (routes hot, settlements cool, dungeons rising). `grace` is the px a doorway gives before the first contact; `exposure` the px from the most-exposed rest point to the nearest danger; `prox` the px from the nearest spawn to a door/phone/atm/point-trigger. `touches` are entrance→exit crossings forced through a dilated spawner (a real fight to traverse); `side` are optional off-corridor fights. The HARD subset — grace ≥ 16px and prox ≥ 24px — is enforced by the content validator; the rest is taste, reported not gated.
